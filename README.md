# Portfólio Acadêmico

Site pessoal de Sergio Horta da Silva Júnior, estudante do Curso Técnico em Informática no IFMS. Apresenta minha trajetória acadêmica, projetos, feiras e eventos, sites desenvolvidos, habilidades e contato.

Projeto final da disciplina Gerência e Configuração de Serviços de Internet, feito com HTML, CSS e JavaScript, e versionado com Git.

🔗 Site https://sergio-horta.github.io/portifolio-sergio/

## Estrutura

```
├── index.html   # página
├── style.css    # estilos
├── main.js      # conteúdo e interações
└── img/         # imagens
```

## Como ver

Baixe o repositório e abra o `index.html` no navegador.
